# Customer Shopping Behavior Analysis | Python • SQL • PostgreSQL • Power BI • AI
An end-to-end Data Analytics project that transforms customer transaction data into actionable business insights. The project covers Excel data preparation, Python/Pandas data cleaning, feature engineering, PostgreSQL/pgAdmin integration, SQL-based business analysis, and Power BI dashboard development.

🔍 Project Workflow

Excel Dataset → Python/Pandas → PostgreSQL/pgAdmin → SQL Analysis → Power BI Dashboard → Business Insights

🛠️ Technologies Used

Python | Pandas | Excel | PostgreSQL | pgAdmin | SQL | Power BI | AI

📊 Analysis Includes
Revenue analysis by gender
High-spending discount users
Top-rated products
Standard vs. Express shipping
Subscriber vs. non-subscriber analysis
Discount-dependent products
Customer segmentation
Top products by category
Repeat buyers and subscriptions
Revenue by age group
🤖 AI-Assisted Workflow

AI was used throughout the project to support Python coding, data-cleaning logic, SQL query development, debugging, analytical exploration, dashboard planning, and insight generation.

💡 Business Focus

The analysis translates transactional data into insights related to customer loyalty, subscriptions, discount strategy, product positioning, and targeted marketing.

Dataset: 3,900 customer purchase records across 18 columns, with customer demographics, purchase details, and shopping-behavior attributes.
